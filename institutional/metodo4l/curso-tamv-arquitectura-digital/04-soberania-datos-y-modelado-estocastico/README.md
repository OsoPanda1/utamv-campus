# Módulo 4 · Soberanía de datos y modelado estocástico

## Propósito

Este módulo permite dominar incertidumbre, destino de datos, dependencia tecnológica y escenarios probabilísticos.

## Resultado esperado

El estudiante diseña un diagnóstico de soberanía de datos y un modelo de escenarios para decidir bajo incertidumbre.
