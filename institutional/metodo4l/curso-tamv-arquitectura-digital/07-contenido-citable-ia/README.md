# Módulo 7 · Contenido citable por IA

## Propósito

Este módulo permite diseñar contenido estructurado, verificable y recuperable por humanos y motores de respuesta.

## Resultado esperado

El estudiante convierte conocimiento institucional en piezas citable-by-design con estructura semántica, fuentes y criterios de actualización.
