# 02 · Diferencias entre enfoque tradicional y Método 4L

## Enfoque tradicional

El enfoque tradicional suele iniciar por táctica: publicar más, invertir más, rediseñar más o automatizar más. Su riesgo principal es optimizar una pieza sin comprender el sistema que la produce.

## Enfoque 4L

El Método 4L inicia por lectura sistémica. No pregunta primero “qué herramienta uso”, sino “qué estructura está generando este resultado”.

| Dimensión | Tradicional | 4L |
|---|---|---|
| Inicio | Acción inmediata | Landscape del sistema |
| Criterio | Métrica aislada | Relación causal |
| Intervención | Campaña o herramienta | Palanca estructural |
| Aprendizaje | Reporte final | Protocolo reutilizable |
| Riesgo | Activismo táctico | Lentitud inicial si no se delimita |

## Regla práctica

Si no puedes explicar qué relación del sistema cambia tu acción, todavía no tienes intervención 4L: tienes una tarea.
