# 08 · Actividad 4L con caso ejemplo

## Caso

Una escuela en línea tiene tráfico creciente, pero baja inscripción. El equipo propone aumentar pauta.

## Trabajo requerido

1. Dibuja el Landscape del embudo: tráfico, landing, formulario, atención, pago, onboarding.
2. Identifica tres fricciones posibles.
3. Prioriza una palanca.
4. Diseña un loop de siete días.
5. Define una métrica EOCT principal y dos métricas de daño.
6. Escribe la regla Learn esperada.

## Entrega breve

Una hoja con mapa, hipótesis, experimento y criterio de aprendizaje.
