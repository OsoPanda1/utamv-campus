# Módulo 3 · El mercado digital como sistema vivo

## Propósito

Este módulo permite comprender el mercado como sistema adaptativo, no lineal y relacional.

## Resultado esperado

El estudiante diagnostica comportamientos de mercado como efectos de estructura, señales, incentivos, narrativas y retroalimentaciones.
